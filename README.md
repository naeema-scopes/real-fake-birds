# The Real Fake Birds of Abu Dhabi

Role(s): Interactive Designer, Front-End Developer - Communications Lab Course, 2019

An interactive online comic about NYU Abu Dhabi's palm tree birds conspiracy ("the birds are fake"). My role included developing comprehensive wireframes for the website layout, implementing the interface through HTML, CSS, and JavaScript, and animating character illustrations into GIFs using Photoshop, aimed at creating an engaging digital storytelling experience that playfully explores campus folklore through interactive comic panels.

Use the interactive buttons + the navigation bar to progress through the comic.
